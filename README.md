# OrbanPhoto – descărcare

Plugin pentru Adobe Lightroom Classic care învață stilul de editare al fotografului și îl aplică automat (inclusiv măști AI pentru față, piele și fundal).

**Descarcă ultima versiune:** [Releases → Latest](../../releases/latest)

| Fișier | Pentru |
|---|---|
| `OrbanPhoto-Mac-offline-….zip` | Mac cu Apple Silicon (M1 sau mai nou), macOS 15+ |
| `OrbanPhoto-Windows-offline-….zip` | Windows 10/11, 64 de biți |

Kiturile sunt complete și se instalează **fără internet**. Nu conțin nimic învățat: fiecare calculator învață stilul din catalogul lui sau îl importă dintr-un fișier `.orbanstyle`.

**Mac:** dezarhivează → clic dreapta pe „Instalează OrbanPhoto.command” → Deschide → Deschide.
**Windows:** clic dreapta pe arhivă → Extrage tot… → dublu-clic pe „Instaleaza OrbanPhoto.bat”.
